### Takeaway

**I. Transcript-level details of the key videos (from auto-captions)**

## Q2. Which transcript method worked?

### Takeaway

- yt-dlp 2026.08.19 flat search (`ytsearchN:`) works and returns id/title/channel/views/duration, but YouTube shows English auto-translated titles for non-English videos (e.g., Fernando Valon's original title is "Como EDITAR e fazer MOTION GRAPHICS no CLAUDE Code (Remotion)") — [YouTube](https://www.youtube.com/watch?v=ntHLmj-GqF0)

## Q4. What makes the biggest difference in quality, and what pitfalls do creators report?

### Takeaway
Consensus across the most-watched Opus 5.5 videos and the Movez course: the model/prompt is ~10% of the result; the "harness" is the rest — house rules that ban generic looks, real assets (never redrawn UI), named/attached references turned into a written style guide and shot list, a beat grid with synced SFX and good voice, spring physics, and a self-critique loop on rendered contact sheets with scores, plus high effort settings.

### Cited Findings
- "The prompt is only 10% of the result. The other 90% is the harness"; generic result = "centered text and a gradient". — [Lukas Margerie, YouTube](https://www.youtube.com/watch?v=747ZnEtsRbg)
- Movez's full course (X article, copied on Substack; referenced by Lukas Margerie) — [Substack](https://movez.substack.com/p/how-to-build-motion-design-studio) / [X](https://x.com/0xMovez/status/2104216919033192746):
  - Engine: every film is a pure function of time (`draw(t)`/`seek(t)`); no CSS transitions, timers, requestAnimationFrame or carried state; seeded noise instead of Math.random; H.264 CRF 16.
  - Effort: `xhigh` for new films, `max` for flagship pieces, `medium` for small fixes (Opus defaults to medium).
  - CLAUDE.md "look" rules: ban centered-title-on-gradient, everything-fades-in, corner labels, frame borders, UI glow, generic particle bursts; one display font + one UI font + one accent color; "something new must happen every 2 to 4 seconds".
  - Real assets: "never redraw product UI from imagination"; gather real screenshots/logo (Playwright), list assets before animating.
  - Brand-reel beats (2–4 s each): problem hook in kinetic type → product UI assembling → three feature moments with a real cursor action → one proof metric → logo + CTA; build 9:16 first, then 1:1/16:9 from layout functions (never crop 16:9 to vertical).
  - References: naming a style beats describing it; extract a frame every 0.5 s with ffmpeg, write `style_guide.md` (palette, type, shot lengths, transitions, camera moves, texture, text entry/exit) and `shotlist.md`, approve before coding; take the reference's grammar, never its content.
  - Spec template (most bookmarked): one container morphs through UI states without cuts; a cursor drives every change; warm neutral canvas, one accent; springs with tiny overshoot; banned: bouncy easing, glows, gradients on UI, particle bursts, dead time; 120 BPM over 8 bars with an action on every beat; render at 60 fps with 4 subframes blended for motion blur; gotcha: no `will-change` on camera-scaled elements (blurry text).
  - Springs: closed-form damped springs; `track(t, keys)` sums one spring per target change; presets snappy/default/heavy (big type, 3D objects, logo lockups — no overshoot)/playful.
  - Sound: librosa beat detection → `beats.json`; synthesized SFX (click, pop, thump, whoosh) on cues; mix to -14 LUFS; voice via API key in `.env` (ElevenLabs example).
  - Director brief: logline, references, tools/budget, look, beat sheet with a payoff every 3–5 s and a hook in the first 2 s; gates: plan → stills → animatic → full animation → polish → sound → render; subagents per chapter sharing an `ANIMATION_GUIDE.md`; ≥3 critique rounds per shot.
  - Critique loop: contact sheet at 2 fps; 12-frame strips around fast actions; "phone test" at 1 fps scaled to ~360 px; loop check; determinism hash check; act as "a harsh motion director, not a proud author"; score 1–10 on hook, phone readability, motion quality, variety, composition, brand accuracy, sound sync; fix the three worst issues and re-render until all ≥8.
  - Pitfalls: one-line prompts test the engine not the idea; identical prompts give similar output ("brief contagion"); showcased pieces needed "dozens to hundreds of model calls"; Opus defaults to a single-HTML route unless Remotion/HyperFrames are named explicitly.
