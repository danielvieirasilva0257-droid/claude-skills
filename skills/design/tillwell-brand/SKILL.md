# Tillwell brand

Tillwell is point-of-sale software for independent shops, with a pocket-size card reader: take payments, track stock and see the day's sales from one app.

Before designing, read the reference file for what you are making:
- `references/colors.md`
- `references/typography.md`
- `references/logo.md`
- `references/voice.md`
- `references/photography.md`

Use `assets/tillwell-logo.png` for the logo and `assets/tillwell-logo-receipt.png` on Register Green. Never redraw the logo. Use `assets/tillwell-reader.jpg` as the product photo.
